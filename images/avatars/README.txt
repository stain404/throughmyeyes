Drop profile-photo images here to replace the colored-circle placeholders
in the Instagram-style following list / profile mockup (Scene B).

Filename must match the username exactly, e.g.:

  bisma_.png        -> her avatar + profile photo
  sara_k22.png
  mike.travels.png
  ...

The full list of usernames lives in TME.Data.igFollowingList in
js/data.js (marked #EDIT-AVATARS). Any username without a matching file
here automatically falls back to a colored circle with its first letter —
no code changes needed either way.
